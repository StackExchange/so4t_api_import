# Historical Python importer

These files are retained only for historical reference. They depend on API v2 for articles and impersonation and are not maintained or recommended for use.

Dependency pins receive security updates, but this does not restore support for the historical importer. The pinned dependencies require Python 3.10 or newer.

Use the standalone [`../index.html`](../index.html) importer instead. It uses API v3 for all supported operations. The old CSV templates in this directory use account IDs for impersonation; the new author-preserving templates require **site user IDs**.
