Connection troubleshooting

The API must allow this page’s origin, Authorization and Content-Type headers, and GET/POST requests through CORS. An opened HTML file usually has origin null.

If blocked, ask your administrator to host this same file on the API’s origin or an approved origin. Hosting on localhost alone does not grant cross-origin access.

Credentials and progress are kept in memory only. Reloading clears them. Imports create new posts; they do not update or deduplicate existing content.
